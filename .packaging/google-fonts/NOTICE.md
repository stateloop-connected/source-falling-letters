# Self-hosted Google Fonts

Added by Stateloop packaging so players' browsers never contact Google. The files are the exact
stylesheets and WOFF2 files Google Fonts serves for the game's own font request; each family keeps
its licence from google/fonts at e7db6ca603fd4862010383ff17ffd6cc4ffac1c0.

- DM Mono: OFL-1.1 (google/fonts `ofl/dmmono/OFL.txt`)
- Space Grotesk: OFL-1.1 (google/fonts `ofl/spacegrotesk/OFL.txt`)

Source stylesheets:

- `https://fonts.googleapis.com/css2?family=DM+Mono:wght@400;500&family=Space+Grotesk:wght@400;500;600;700&display=swap` (sha256 63b16ab6130707789e7d1fe26637d32e4f278ab3cd7e346319fbb3b157ed531d)
